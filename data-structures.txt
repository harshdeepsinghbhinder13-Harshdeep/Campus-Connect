1. Abstract data types
An abstract data type describes a collection of values and its supported
operations, without prescribing how those operations are implemented.
For a stack, the operations include push, pop, peek, and isEmpty.

2. Arrays and linked lists
An array stores elements contiguously. Indexed access is O(1); inserting
at the beginning requires shifting elements and takes O(n).
A linked list stores nodes connected by references. Finding the nth node
takes O(n). Inserting after a known node can be O(1).

3. Time and space complexity
Big-O describes an asymptotic upper bound as input size grows.
Linear search: O(n) time, O(1) additional space.
Binary search on a sorted array: O(log n) time.

Practice
- Implement a stack using an array.
- Compare the costs of inserting into an array and a linked list.
- Explain why binary search requires ordered data.
